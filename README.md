# 🌸 Acqua Flores — Website

Projeto de desenvolvimento web criado para representar a floricultura **Acqua Flores**, com foco em prática de **HTML, CSS e estruturação de interfaces modernas**.

O objetivo deste projeto é simular um **website real de uma floricultura**, aplicando conceitos de **design, responsividade e organização de código**, enquanto desenvolvo minhas habilidades como desenvolvedora front-end.

## ✨ Sobre o Projeto

Este site foi desenvolvido **inteiramente à mão**, sem uso de frameworks ou templates prontos.
Cada parte da interface foi construída manualmente para praticar e aprofundar conhecimentos em desenvolvimento web.

O projeto busca reproduzir a experiência de um **site profissional de floricultura**, com layout elegante e focado na experiência do usuário.

## 🎯 Objetivos do Projeto

* Praticar **HTML semântico**
* Desenvolver **layouts modernos com CSS**
* Treinar **responsividade (mobile first)**
* Criar um **projeto realista para portfólio**
* Simular o website de uma empresa real

## 🛠 Tecnologias Utilizadas

* **HTML5**
* **CSS3**
* **Google Fonts**
* **Flexbox**
* **Design Responsivo**

## 🎨 Design

O design foi pensado para transmitir a estética de uma **floricultura elegante e delicada**, utilizando:

* Paleta de cores inspirada em flores e natureza
* Tipografia sofisticada
* Layout limpo e moderno
* Destaque visual para produtos

## 📱 Responsividade

O projeto está sendo desenvolvido com abordagem **Mobile First**, garantindo adaptação para diferentes tamanhos de tela:

* 📱 Mobile
* 💻 Desktop
